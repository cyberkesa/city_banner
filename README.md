# Городской 3D-баннер

Интерактивный 3D-каталог с прокруткой сцены, категориями товаров и переходами
в каталог. В проект входят баннер и два локальных редактора сцены.

Сцена прокручивается автоматически; плашки показывают категории товаров в
кадре. Ручная прокрутка, касание и редактирование сцены приостанавливают
движение. Автопрокрутка возобновляется через 4 секунды после взаимодействия.
Курсор над товаром или плашкой не останавливает движение.

## Запуск

Нужны Node.js 22.12+ и npm. Модели, текстуры и карта сцены включены в репозиторий.

```bash
npm ci
npm run dev
```

Откройте адрес, который появится в терминале.

## Редакторы

Редактор ландшафта — дорожки, покрытия и растения:

```bash
npm run editor
```

3D-редактор — размещение объектов:

```bash
npm run editor:3d
```

Оба редактора работают с картой `banner/public/landscape-map.json`.

## Проверка и сборка

```bash
npm run check
```

Команда запускает тесты, проверяет типы и собирает проект.
Готовый баннер находится в `dist/client/`.

Для сборки без запуска тестов:

```bash
npm run build
```

## Структура

- `index.html` — страница баннера.
- `banner/src/` — код 3D-сцены и интерфейса.
- `banner/public/` — модели, текстуры и карта сцены.
- `editors/` — редакторы ландшафта и объектов.
- `assets/models-source/` — резервные исходные модели.
- `build/` — формирование каталога моделей.
- `worker/` и `wrangler.jsonc` — конфигурация Cloudflare.
- `vercel.json` — конфигурация Vercel.
