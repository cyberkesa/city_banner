# Редактор ландшафта

Редактор покрытий, дорожек, растений и объектов. Размер карты — 70 × 50 м.

## Запуск

Из корня проекта:

```bash
npm ci
npm run editor
```

На macOS можно запустить `Открыть_редактор.command`. Он устанавливает
зависимости при первом запуске и открывает редактор. Окно терминала должно
оставаться открытым, пока работает редактор.

## Инструменты

- **Выбор** — выбор и перемещение объектов и точек контура.
- **Зона** — газон, земля, песок, резиновое покрытие или плитка.
- **Дорожка** — пешеходная дорожка заданной ширины.
- **Дерево / Куст** — размещение растения.
- **Объект** — размещение модели.
- **Деревья / Кусты линией** — расстановка растений вдоль линии.
- **Деревья / Кусты зоной** — заполнение области растениями.

`Enter` или двойной клик завершают фигуру. `Esc` отменяет рисование.
Те же действия доступны кнопками **Завершить** и **Отменить**.
Кнопка **Убрать точку** удаляет последнюю точку.

Автомобильная дорога задаётся отдельно от редактируемых покрытий. При
рисовании пешеходной дорожки точка на асфальте переносится к ближайшему бордюру.

## Навигация

- Колесо мыши — масштабирование под курсором.
- `Пробел` и перетаскивание или средняя кнопка мыши — перемещение карты.
- **Вся карта** — полный обзор.
- **Показывать бесшовный стык** — отображение соседних повторов сцены.

## Сохранение

**Сохранить карту** записывает изменения в `banner/public/landscape-map.json`.
**Открыть 3D** открывает просмотр сцены.

**Скачать JSON** экспортирует карту, **Импорт** загружает её из файла.
Карты старого формата шириной 45 или 90 м преобразуются к ширине 70 м.

Незавершённый черновик хранится в браузере и восстанавливается при следующем
запуске. Для записи изменений в проект используйте **Сохранить карту**.
