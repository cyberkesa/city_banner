# Редакторы

- `landscape/` — редактирование карты, покрытий, растений и объектов.
- `scene/` — перемещение, поворот, масштаб и высота объектов в 3D.
- `vite.config.ts` — локальный сервер и сохранение карты.

Запускайте команды из корня проекта после установки зависимостей (`npm ci`).

Редактор ландшафта:

```bash
npm run editor
```

3D-редактор:

```bash
npm run editor:3d
```

Карта сохраняется в `banner/public/landscape-map.json`.
